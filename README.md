# 과제 보드 — 구글 시트 + GitHub Pages 버전

이 폴더에는 파일 3개가 있어요.

- `index.html` — 팀이 실제로 보는 웹페이지 (GitHub Pages에 올릴 파일)
- `Code.gs` — 구글 시트에 붙여넣을 백엔드 스크립트 (Apps Script)
- `README.md` — 지금 보고 있는 이 설명 파일

데이터는 구글 시트 안에 새로 생기는 **"AppData"** 탭에 저장돼요. 기존에 쓰시던
"26년 9월 과제 리스트" 탭은 그대로 두고 건드리지 않아요.

---

## 1단계. 구글 시트에 백엔드 붙이기 (Apps Script)

1. 과제를 관리하는 구글 시트를 엽니다.
2. 상단 메뉴에서 **확장 프로그램 > Apps Script**를 클릭해요.
3. 열린 편집기에 원래 있던 코드를 전부 지우고, `Code.gs` 파일 내용을 통째로 붙여넣어요.
4. 저장(Ctrl+S / Cmd+S) 해요.
5. 오른쪽 위 **배포 > 새 배포**를 클릭해요.
6. 유형에서 톱니바퀴를 눌러 **웹 앱**을 선택해요.
7. 아래 설정으로 지정해요:
   - **실행 계정**: 나 (본인)
   - **액세스 권한**: 전체 공개 ("Anyone")
     > ⚠️ 이 설정은 배포 URL을 아는 사람은 누구나 로그인 없이 AppData 탭을
     > 읽고 쓸 수 있다는 뜻이에요. GitHub Pages 같은 외부 정적 페이지에서
     > 로그인 세션 없이 호출하려면 이 설정이 필요해요. 사내 일정 정도의
     > 민감도라면 보통 괜찮지만, 더 엄격하게 막고 싶다면 Firebase 같은
     > 별도 데이터베이스 방식을 고려해 보세요.
8. **배포**를 누르고, 구글 계정 권한 승인 화면이 뜨면 승인해요.
9. 배포가 끝나면 `.../exec`로 끝나는 **웹 앱 URL**이 나와요. 이 주소를 복사해 두세요.

> 나중에 `Code.gs` 내용을 수정하면, **배포 > 배포 관리 > 연필 아이콘 > 버전:
> 새 버전 > 배포**를 눌러야 변경 사항이 실제로 반영돼요. (그냥 저장만 하면
> 기존 배포 주소는 이전 코드로 계속 동작해요.)

---

## 2단계. 웹페이지에 URL 연결하기

1. `index.html` 파일을 텍스트 편집기로 열어요.
2. 아래 줄을 찾아요 (스크립트 맨 앞부분에 있어요):

   ```js
   var API_URL = "PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE";
   ```

3. 따옴표 안을 1단계에서 복사한 실제 `.../exec` 주소로 바꿔요.
4. 파일을 저장해요.

---

## 3단계. GitHub Pages로 올리기

1. [github.com](https://github.com)에서 새 저장소(Repository)를 만들어요. Public으로 만들면
   무료로 바로 Pages를 쓸 수 있어요.
2. 이 폴더의 `index.html`을 저장소에 업로드해요 (README.md, Code.gs는 올리지
   않아도 되지만, 나중에 참고하려면 같이 올려도 괜찮아요).
3. 저장소 메뉴에서 **Settings > Pages**로 들어가요.
4. **Source**를 "Deploy from a branch"로 두고, 브랜치는 `main` (또는 `master`),
   폴더는 `/ (root)`로 선택한 뒤 저장해요.
5. 1~2분 기다리면 `https://<계정이름>.github.io/<저장소이름>/` 형태의 주소가
   생겨요. 이 링크를 팀원들과 공유하면 돼요.

---

## 확인하기

1. 위에서 만든 GitHub Pages 링크를 열어요.
2. 처음 열면 시트가 비어 있을 경우 자동으로 기존 과제 20건이 등록돼요
   (등록이 안 되면 화면에 나오는 "시트 과제 20건 불러오기" 버튼을 눌러요).
3. 구글 시트로 돌아가서 **AppData** 탭을 확인하면, 웹페이지에서 등록한
   내용이 그대로 행(row)으로 들어가 있는 걸 볼 수 있어요.
4. 팀원 두 명이 각자 브라우저에서 같은 링크를 열어 과제를 하나씩 등록해
   보고, 새로고침(또는 8초 자동 새로고침)했을 때 서로의 내용이 보이는지
   확인해요.

## 문제 해결

- **"불러오기에 실패했어요: ..." 메시지가 뜰 때**: 화면에 같이 뜨는 에러
  문구를 확인하세요.
  - `API_URL`이 `PASTE_YOUR_...`로 시작한다는 안내가 뜨면 → 2단계를
    다시 확인하세요.
  - `Failed to fetch` 또는 CORS 관련 에러 → Apps Script 배포 시
    **액세스 권한을 "전체 공개(Anyone)"로 설정했는지**, 그리고 최신
    코드로 **새 버전 배포**를 했는지 확인하세요.
  - `HTTP 401` 또는 `HTTP 403` → 배포 권한 설정 문제일 가능성이 커요.
    배포 관리 화면에서 액세스 권한을 다시 확인하세요.
- **등록/수정한 내용이 다른 사람 화면에 안 보일 때**: 8초마다 자동으로
  새로고침되니 잠시 기다려 보고, 그래도 안 되면 우측 상단의 새로고침
  버튼(⟳)을 눌러보세요.
- **기존 과제 20건이 중복으로 계속 등록될 때**: `Code.gs`의 `seedTasks_`는
  AppData 탭에 데이터가 하나라도 있으면 아무것도 하지 않도록 되어 있어요.
  중복이 생겼다면 AppData 탭에서 직접 중복 행을 지워주세요.
