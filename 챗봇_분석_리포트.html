1고객 질문 유형 분류

고객 메시지의 키워드 패턴으로 11개 유형을 도출했어요. 대화방 단위로 가장 빈번한 유형을 대표 카테고리로 지정했어요.

2유형별 1:1 문의 이동률

전체 평균은 20.9%. 빨간 점선보다 위에 있는 카테고리가 챗봇 답변에 만족하지 못해 상담 채널로 이탈하는 비율이 높은 영역이에요.

처리 상태/진행 확인 (이탈률 33.3%) — "언제 도착하나요", "이용내역 확인이 안돼요" 같은 주문별 실시간 상태 조회가 필요한 질문에서 챗봇이 일반 안내만 제공해 이탈이 가장 큽니다.
수거/배송 (이탈률 24.3%, 절대량 최대) — "수거 안 해가고 돈 나감", "오수거", "수거 시간 변경" 등 개별 케이스 처리 요청이 많아 정형화된 답변으로는 한계가 있어요. 1:1 이탈 절대 건수가 가장 많은 영역(54건)입니다.
결제/환불 (이탈률 22.9%) — "포인트가 안 들어왔다", "할부", "세탁비 환불 방법" 등 계정/거래내역 기반 답변이 필요해 일반 정책 안내로는 부족합니다.
세탁 결과/손상 (이탈률 7.4%, 낮음) — 실제로는 강한 보상 요구가 많은 영역이지만, 챗봇이 "앱 내 [문의하기] 사진 첨부" 경로로 우회 안내해 1:1 이동이 낮게 집계됨. 실질 만족도는 별도 측정이 필요해요.
이용 방법/서비스 안내 (이탈률 9.7%) — FAQ성 정보 제공이 잘 작동하는 영역. 이 베이스라인을 다른 카테고리에도 확장하는 것이 목표예요.

3가장 자주 들어오는 질문 TOP 15

버튼 클릭 형태의 짧은 질의 + 자유 입력. 상위 10개가 전체 메시지의 약 16%를 차지해요. 빠른 응답 슬롯과 자동 안내문을 정교화할 여지가 큽니다.

4챗봇 고도화 — 우선순위 권장사항

이탈률 × 트래픽 영향도 기준 우선순위. P1이 가장 시급해요.

P1주문 상태 실시간 조회 연동

"언제 도착해?", "지금 어디?", "이용내역" 류 질의에 사용자별 주문 데이터를 직접 호출해 답변하도록 연동.

  • 대상: 처리 상태(33.3% 이탈), 수거/배송 일부
  • 예상 효과: 두 카테고리 1:1 이탈 30~50% 감소

P1예외 케이스 처리 워크플로우

"수거 안 해감", "오수거", "일부만 배송" 등 표준 안내가 무력한 케이스에 자동 보상/재수거 신청 흐름 연결.

  • 대상: 수거/배송 222 대화 중 24.3%가 이탈
  • 구조화된 보상 신청 폼 + 사진 첨부 자동화

P2계정·결제 내역 기반 응답

포인트 잔액, 결제 내역, 쿠폰 적용 가능 여부 등을 인증된 사용자에게 직접 표시.

  • 대상: 결제/환불 96건, 22.9% 이탈
  • "왜 포인트가 없죠?" 류는 데이터 조회 1회로 해결

P2구독 해지 자동화 우회 차단

"해지/취소" 의도가 명확하면 챗봇 내에서 즉시 해지 → 결제일/잔여혜택 안내 → 진행. 현재는 1:1 유도가 잦음.

  • 대상: 구독/요금제 138건, 18.8% 이탈
  • 해지 사유 수집(설문)으로 retention 인사이트 확보

P3품목·소재 판정기 강화

"○○ 세탁 가능한가요?" 류에 품목/소재 DB 기반으로 즉시 가/불가 + 이유 + 대안 제시.

  • 대상: 세탁불가/품목 100건, 20% 이탈
  • 이미지 업로드 → 소재 추정(비전 모델) 적용 검토

P3"기타" 137건 재분류·재학습

인사·짧은 응답·우회 표현이 다수. 의도 분류기를 LLM 임베딩 기반으로 재학습해 분류 사각지대 제거.

  • "좋은 아침이야" 같은 잡담 vs 추가 질문 구분
  • "극세사 토퍼 얼만가요?" 등 가격 의도 별도 카테고리화

5분석/고도화에 추가로 필요한 데이터

현재 데이터로는 의도와 결과만 추정할 수 있어요. 아래 항목이 함께 수집되면 분석 정확도와 자동화 범위가 크게 늘어나요.

1. AI 응답 만족도 (👍/👎)

현재 점수(1/5/N) 컬럼이 거의 비어 있음(2건). 매 답변마다 만족도를 수집해야 어떤 답변이 실패했는지 정확히 알 수 있어요.

2. 사용자 의도 라벨

키워드 매칭은 노이즈가 많음. 운영자가 200~500건만 골든셋으로 라벨링하면 분류기 정확도 80%+ 확보 가능.

3. 1:1 이동 후 처리 결과

이동 후 어떤 카테고리로 종결됐는지(환불/재수거/단순안내 등). 어떤 케이스가 정말 사람 손이 필요한지 구분돼요.

4. 사용자 메타정보

구독 여부, 가입일, 이용횟수, 지역. "신규 유저는 이용방법 질문이 많고, 장기 유저는 손상/보상이 많다" 류 코호트 분석 가능.

5. 주문/세탁 진행 데이터 연동

대화 시점의 해당 사용자 주문 상태. "언제 도착?" 질의가 들어왔을 때 챗봇이 즉답할 수 있는 핵심 자원.

6. 응답 지연 시간(latency)

AI 응답 시간이 느린 영역에서 이탈률이 높을 수 있음. 메시지별 처리 시간 기록 필요.

7. 답변 내 링크 클릭률

현재 답변엔 [자세히 보기] 링크가 많음. 클릭률이 낮은 안내문은 본문에 핵심을 직접 노출하도록 개선해야 함.

8. 재방문/연속 대화 식별자

같은 사용자가 여러 대화방에서 동일 질문을 반복한다면 이전 답변 실패 신호. 사용자 키 기반 시계열 추적 필요.

9. 운영자 검수 정답

실제 1:1 상담사가 보낸 답변과 챗봇 답변의 diff 데이터. 가장 강력한 학습 시그널이에요.
